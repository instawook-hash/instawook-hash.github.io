뭉토 업로더 개인정보처리방침

시행일: 2026년 10월 26일

1. 누가 쓰나요

뭉토 업로더는 '뭉토 · 쫑긋마을' 작가 본인만 사용하는 개인용 도구입니다. 다른 사용자에게 제공하지 않습니다.

2. 어떤 정보에 접근하나요

  • YouTube 업로드 권한: 작가 본인 채널에 영상을 올리기 위해 사용합니다.
  • YouTube 읽기 권한: 본인 채널 영상의 조회 수, 좋아요, 공개 댓글 내용을 읽습니다.
  • YouTube Analytics 읽기 권한: 본인 채널 영상의 시청 시간 통계를 읽습니다.

3. 어떻게 쓰나요

읽은 정보는 작가 본인에게 보내는 주간 운영 보고서를 만드는 데에만 씁니다. 댓글은 작성자 정보 없이 내용만 요약에 사용합니다. 보고서와 통계는 작가 본인만 볼 수 있는 비공개 저장소에 보관합니다.

4. 다른 곳에 주나요

판매하거나 광고에 쓰지 않습니다. 보고서 요약을 만들 때 AI 분석 서비스(Anthropic Claude API)에 통계와 댓글 내용이 전달될 수 있으며, 그 밖의 제3자에게 제공하지 않습니다.

5. Google API 정책 준수

뭉토 업로더가 Google API로 받은 정보의 사용과 전송은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다. 이 도구는 YouTube 서비스 약관과 Google 개인정보처리방침의 적용을 받는 YouTube API 서비스를 사용합니다.

6. 권한 철회

Google 계정 → 보안 → 타사 액세스에서 언제든 접근 권한을 해제할 수 있습니다. 해제하면 더 이상 정보를 읽지 않습니다.
